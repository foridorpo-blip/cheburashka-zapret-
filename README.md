## 🚀 Что нового в версии v0.1.2:

*   🛡️ **Авто-исключения Windows Defender:** Инсталлятор теперь автоматически добавляет `winws.exe` и драйвер `WinDivert64.sys` в исключения Защитника Windows. Больше никаких ложных срабатываний и удалений файлов антивирусом!
*   ⚡ **Автоматический сброс DNS-кэша:** При каждом запуске или перезапуске службы система сама выполняет команду `ipconfig /flushdns`. Новые сетевые маршруты к YouTube и Discord применяются мгновенно без перезагрузки ПК.
*   🔄 **Быстрый перезапуск сервера:** В интерактивный сервис-менеджер добавлен пункт меню для моментальной перезагрузки фоновой службы `CheburashkaZapretService` в один клик (удобно после обновления списков сайтов).
*   📝 **Инструкции в пользовательских списках:** Файл `list-general-user.txt` больше не создается пустым — в него добавлены понятные закомментированные примеры и подсказки, как правильно вносить свои домены.
*   📦 **Повышенная автономность:** Оптимизирована логика относительных путей для бесперебойной работы сборки прямо с Рабочего стола Windows, привязанного к облаку OneDrive.

## ⚙️ Инструкция по установке:

1. Скачайте **`чебурашка-запрет.zip`** или **`чебурашка-запрет.rar`** из последнего релиза.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Нажмите правой кнопкой мыши на файл **`service.bat`** (или `install-service.cmd`) и выберите **«Запуск от имени администратора»**.
4. В открывшемся меню выберите пункт **1** для установки и автоматического запуска вечной фоновой службы.
5. Пользуйтесь свободным интернетом! Окно консоли можно закрывать, сервер тихо работает невидимкой в процессах Windows.
