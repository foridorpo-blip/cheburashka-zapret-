# чебурашка-запрет v0.1.2

Кастомная модификация оригинального сервис-менеджера **zapret (winws.exe) v1.10.2**. Сборка предназначена для автоматизации настройки обхода DPI.

---

## 🛠 Что реально изменилось в v0.1.2:

* **Сброс DNS-кэша:** В скрипт запуска добавлена команда `ipconfig /flushdns`. Она принудительно очищает кэш маршрутов Windows при каждом старте или перезапуске службы, чтобы новые правила для доменов YouTube и Discord применялись сразу без перезагрузки компьютера.
* **Перезапуск службы одной кнопкой:** В меню `service.bat` добавлен отдельный рабочий пункт для быстрого рестарта фоновой службы `CheburashkaZapretService`. Больше не нужно сначала удалять службу, а потом ставить её заново, если вы изменили списки сайтов.
* **Примеры в списках:** Файл `list-general-user.txt` теперь создается с закомментированными текстовыми подсказками, показывающими правильный синтаксис внесения доменов вручную.
* **Исправление путей:** Логика скриптов полностью переведена на относительные пути `"%~dp0"`, что убирает сбои при запуске из папок синхронизации (например, OneDrive).

---

## ⚠️ Честное предупреждение по поводу антивирусов (Важно):
Эта сборка **НЕ умеет** автоматически добавлять себя в исключения Windows Defender, так как Microsoft полностью заблокировала возможность сторонним скриптам изменять настройки безопасности Защитника без ручного подтверждения пользователя. 

Если ваш антивирус или Windows Defender ругается на драйвер `WinDivert64.sys` или бинарник `winws.exe` — это стандартное ложное срабатывание на низкоуровневые сетевые утилиты. **Вам необходимо добавить папку с программой в исключения своего антивируса ВРУЧНУЮ.**

---

## 📦 Как запустить:
1. Скачайте архив проекта из раздела файлов.
2. Распакуйте в любую локальную папку на диске.
3. Откройте **`service.bat` от имени администратора**.
4. Нажмите **1** для установки фоновой службы.
